# WEB-TECHNOLOGY
Web technology uses HTML to build webpage structure, CSS to style and layout content, and JavaScript to add interactivity and dynamic behavior. Together, they create modern, engaging web experiences seen in websites and apps. HTML forms the skeleton, CSS designs the look, and JavaScript enables user interaction, animations.

Web Development Project
This repository contains HTML, CSS, and JavaScript files demonstrating various web development tasks such as creating a class timetable table, multi-frame webpage layout, CSS styling methods, embedding media, form validation, simple calculator, and array sorting function. Each example is designed to teach fundamental front-end web development concepts.

Features
Class timetable presented in an HTML table.

Webpage split into three frames for content, main body, and remarks.

Demonstration of inline, internal, and external CSS usage.

Embedded audio and video elements.

Employee registration form with input validation.

Simple calculator for basic arithmetic operations using JavaScript.

User-defined JavaScript function for sorting an array with HTML5 interface.

How to Download and Run
Download files:

Visit the GitHub repository page.

Click the green "Code" button.

Select "Download ZIP" and save the ZIP file to your computer.

Extract the ZIP archive to a folder.

Open files:

Navigate to the extracted folder.

Open any .html file in a modern web browser (e.g., Chrome, Firefox, Edge).

No server setup is required; these are static web files.

Run interaction:

For interactive examples like the form and calculator, simply use the browser interface to test features.

Audio and video elements can be played directly in the browser.

Validation and JavaScript functionalities work upon user input.

Requirements
A modern web browser with HTML5 support.

No additional software or server needed.
